Software Development

Full-Stack Task Manager

Developed a full-stack task management application that allows users to organize, track, and manage their daily tasks through a responsive web interface. The application includes Google OAuth authentication, user-specific task storage, and persistent database operations.

Built using a client-server architecture, the application connects a Vue.js frontend to a Node.js and Express backend through RESTful API endpoints. MongoDB Atlas handles persistent storage, while Progressive Web App functionality supports access across web and mobile devices.

Enterprise Network Design & Security

Designed a secure network infrastructure for a fictional pharmaceutical company operating across multiple buildings. The project involved planning network connectivity for office spaces, laboratories, employees, and external guests while accounting for different operational and security requirements.

Developed an IP addressing plan, network topology, bill of materials, and security documentation. The design uses network segmentation to separate internal resources, guest access, and isolated laboratory equipment, helping limit unnecessary communication between network environments.

Flappy Cosmo

Created a BYU-themed recreation of the classic Flappy Bird game using Python and Pygame. Players control Cosmo the Cougar, navigating through obstacles while avoiding collisions with the environment.

Implemented the core game mechanics, including gravity-based movement, keyboard input, randomized obstacle generation, collision detection, and score tracking. The project applies object-oriented programming to organize game elements such as the player, obstacles, and ground into separate components.
